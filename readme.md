# 🚀 Meus Projetos em Python

Olá esse repositorio são apenas alguns projetos que fiz para praticar com tkinter. Sinta-se a vontade para dar uma olhada, os projetos foram inspirados nos tutoriais disponiveis em https://www.geeksforgeeks.org/python/python-tkinter-tutorial/.

---

## 🛠️ Projetos Incluídos

### 1. 🧮 Calculadora (`calculadora`)
Uma aplicação de calculadora desenvolvida com interface gráfica, projetada para realizar operações matemáticas fundamentais de forma simples.
* **Arquivo principal:** `calculadora/calculator.py`


---

### 2. 📁 Gerenciador de Arquivos Tkinter (`file_explorer_tkinter`)
Um explorador de arquivos desktop interativo construído utilizando a biblioteca nativa `Tkinter`.

* **Arquivo principal:** `file_explorer_tkinter/file_explorer.py`

---

### 3. 📊 Representação de Dados de uma API (`lol_champion_randomizer`)
Aqui eu me diverti um pouco. Esse Script consulta um link com os dados dos campeões de league of legends e sorteia um campeão novo sempre que o usuario apertar no butão.

* **Arquivo principal:** `lendo dados de API/lol_champion_randomizer.py`
---

## 🧰 Tecnologias Utilizadas

* **Linguagem:** Python 3.14.2
* **Interface Gráfica:** Tkinter
* **Bibliotecas:** JSON / requests 
---

## 💻 Como Executar os Projetos

1. **Clone o repositório:**
   ```bash
   git clone https://github.com/f3pe/my-study-with-tkinter.git
   cd seu-repositorio
   ```

2. **(Opcional) Crie e ative um ambiente virtual:**
   ```bash
   python -m venv venv
   # No Windows:
   venv\Scripts\activate
   # No Linux/Mac:
   source venv/bin/activate
   ```

3. **Instale as dependências (caso existam):**
   ```bash
   pip install -r requirements.txt
   ```

4. **Execute o projeto desejado:**
   * Calculadora:
     ```bash
     python "calculadora/calculator.py"
     ```
   * Representação de Dados:
     ```bash
     python "lendo dados de API/lol_champion_randomizer.py"
     ```
   * Explorador de Arquivos:
     ```bash
     python "file_explorer_tkinter/file_explorer.py"
     ```
